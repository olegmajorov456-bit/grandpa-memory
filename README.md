# Сайт памяти — Николай Николаевич Сметанин

Vite + React. Деплой через GitHub Pages.

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

После push в `main` GitHub Actions собирает и публикует сайт.

> Админ-панель в текущей версии — прототип на localStorage. Для публичного сайта настоящую авторизацию и хранение контента нужно вынести на серверную сторону.
